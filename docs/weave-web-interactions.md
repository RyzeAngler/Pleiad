# Weave Web 交互说明

启动与 HTTP 契约见 [Web 使用指南](weave-web.md)。浏览器只表达用户操作与读取服务事实；工作执行由服务拥有，关闭页面不会取消任务。

## 导航与草稿

| 入口 | 可见结果 | 保留的状态 |
| --- | --- | --- |
| 聊天 | 独立聊天页，工作区隐藏；导航只高亮聊天 | 消息阅读位置、正文、附件与补充目标 |
| 空间 | 打开空间列表；从聊天返回时恢复最近的空间或工作详情 | 工作区滚动位置、筛选和未保存配置 |
| 资源 | 打开模型、工具、技能和环境目录 | 聊天草稿、进入目录前的来源页面 |
| 返回来源 | 恢复来源页面，焦点回打开内容的控件 | 原列表选择和阅读位置 |
| 浏览器后退、前进 | 按路由恢复页面；离开资源目录时关闭其详情弹窗 | 草稿和各工作区的局部状态 |

输入框默认单行，多行仅增加高度。Enter 发送、Shift+Enter 换行；输入法组合期间不提交。附件、任务目标和只读引用分别保存，不写入正文。

## 工作与执行控制

| 操作 | 行为 |
| --- | --- |
| 补充工作 | 在主输入框上方添加可移除的单行目标标签，聚焦正文；点击本身不发送请求 |
| 取消补充 | 只移除未发送草稿的目标关联，正文继续保留 |
| 发送 | 提交当前正文、附件、目标和引用；重复请求沿用原消息身份 |
| 暂停、继续、取消 | 从工作详情发起，按服务返回的可用动作和状态更新 |
| 重新执行 | 创建新的工作；旧工作的终态和结果保留 |
| 回答待办 | 显式关联问题；已过期或已处理的问题不可重复作答 |

任务状态、模型步骤状态和后台操作状态分别展示。已完成的模型步骤不代表后台动作已经完成；未知结果不会显示成功。

## 执行过程与资料

最新调用和最新步骤排在前面。调用和步骤使用排他的 `before_sequence` 分页，新增步骤不会挤动历史页。初次打开最新步骤后，实时刷新只更新当前阅读范围；点击“查看最新进展”才加载新增步骤。

每个步骤显示实际动作、收到的内容、助手回复以及归属明确的工具结果。工具消息和后台最终结果必须匹配所属调用，读取失败在对应结果处显示。GraphRun、节点尝试与普通步骤保留各自身份和选择。

资料页保留工作说明、授权能力、原始要求及送达、读取、处理状态。产物预览保留来源，下载只读取已经存在的内容。

## 资源详情

模型、工具、技能和环境均可点击。详情展示该资源实际拥有的元数据、配置、输入与输出 Schema、技能原文和文件列表；原始数据可展开和复制。

凭据、授权头、敏感环境变量和 URL 凭据在服务端脱敏后返回。Schema 的参数名称和类型保留，敏感示例值掩码。复制内容与显示内容使用同一份脱敏响应。Escape 关闭详情后，焦点回到原资源行。

## 验证边界

前端回归测试使用真实 React 组件，在 HTTP 和 EventSource 边界提供受控响应；后端测试使用真实服务、Runner 和存储，在外部模型、网络及进程边界隔离依赖。确定性测试与浏览器演示不等同于真实模型、远程 MCP 或 OCI 完整执行验证。

控件、键盘与阅读位置的检查步骤见 [前端验收指南](../apps/weave/web/design-qa.md)。
